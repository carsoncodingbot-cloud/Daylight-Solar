# daylightsolar.ai

Production static site for Daylight Solar (Inland Empire solar funnel).
Served by GitHub Pages from the root of `main` — custom domain `daylightsolar.ai` (CNAME file).

Source of truth: `solar-site/` in the Brand-building-skills repo
(branch `claude/glacier-hvac-business-iizyvt`). To update:
`EXPORT=true npm run build` there, then copy `out/*` here and push.
